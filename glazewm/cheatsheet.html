GlazeWM Keyboard Shortcuts

Omarchy-style · modifier = Alt

Window

Alt+WClose window
Alt+FToggle fullscreen
Alt+TToggle tiling / floating
Alt+Shift+VToggle floating (centered)
Alt+JToggle split direction
Alt+MMinimize

Focus

Alt+←→↑↓Focus window by direction

Move & Resize

Alt+Shift+←→↑↓Move / swap window
Alt+= / -Grow / shrink width
Alt+Shift+=/-Grow / shrink height
Alt+RResize mode (then h/j/k/l)

Resize Mode

H LWidth − / +
K JHeight + / −
Esc EnterExit resize mode

Workspaces

Alt+1…0Go to workspace 1–10
Alt+Shift+1…0Move window → workspace
Alt+TabNext workspace
Alt+Shift+TabPrevious workspace
Alt+Ctrl+TabRecent workspace
Alt+Shift+Ctrl+←→↑↓Move workspace to monitor

Launch Apps

Alt+EnterTerminal (in last cwd)
Alt+Shift+BBrowser (Zen)
Alt+Shift+NEditor (VS Code)
Alt+Shift+EEmail (Outlook)
Alt+Shift+CCalendar
Alt+Shift+GTeams
Alt+Shift+AAI (Gemini)
Alt+Shift+OObsidian
Alt+Shift+FFile manager (Explorer)
Ctrl+Shift+FFile manager (yazi)

WM Controls

Alt+Shift+RReload config
Alt+Shift+PPause / resume WM
Alt+Ctrl+WRedraw all windows
Alt+Ctrl+QExit WM

Clipboard (any app)

Alt+CCopy
Alt+VPaste
Alt+XCut
